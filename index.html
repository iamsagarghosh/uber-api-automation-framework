Effective date: 24 November 2026

Purpose and scope

API Automation Portfolio is a personal software-testing project. It is used by its developer to exercise authorized API scenarios in Uber's sandbox environment. It is not an Uber product, is not affiliated with Uber Technologies, Inc., and is not intended for public sign-up or production ride requests.

Information processed during tests

When the developer runs an OAuth or API test, the test may process:

  • OAuth authorization codes and access tokens needed to authenticate requests;
  • test inputs, which may include pickup and drop-off coordinates supplied for a sandbox scenario;
  • API request identifiers, response status, timing, and response data returned by the sandbox; and
  • test execution results created by the local test runner or its reporting tools.

The project is intended to use synthetic test data and the Uber sandbox only. Do not use real passenger data, production credentials, or production endpoints in this project.

How information is used and shared

Test information is used only to authenticate and validate the API scenarios the developer runs. API requests and the information included in them are sent to Uber's sandbox services, which process them under Uber's applicable terms and privacy practices. The project does not sell test information or use it for advertising.

Storage and retention

OAuth secrets and access tokens should be kept in local environment variables or an approved CI secret store, never in source control, CSV test data, screenshots, logs, or reports. Local test results and generated reports may remain in the project workspace until the developer deletes them. If a CI service is configured, its authorized users and retention settings may also apply to build artifacts. The developer should review and configure those settings before enabling CI runs against the sandbox.

Security

The project is intended to avoid logging authorization headers and secret values. Access to the development machine, repository, and any CI artifacts should be limited to authorized users. No method of storing or transmitting information is completely risk-free.

Your choices

This test application is operated by its developer and does not offer public user accounts. The developer can stop tests, remove local test files and reports, and revoke or rotate application credentials through the relevant developer dashboard. Questions about data handled by Uber should be directed to Uber.
